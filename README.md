El cliente se contactó conmigo a traves de un conocido con el objetivo de que le cree una pagina web para su emprendimiento/trabajo.
Quería una página que sirviera como folleto de bienvenida para las personas que quieran contratar sus servicios de paseos en velero, resolviendo dudas y ahorrandole
tiempo en contestarlas. La pagina da la bienvenida mostrando un carrusel ultra completo con fotos de las enorme cantidad de personas que contrataron el
servicio, asi como informacion sobre la duracion, costos y permisos para llevar a cabo en el paseo. Cuenta con una calculadora para saber cuanto saldria dependiendo
el numero de personas que asistan, y un link de whatsapp que lleva directo a contactar con GoSailingRosario.
